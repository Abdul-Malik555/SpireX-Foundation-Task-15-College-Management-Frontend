## Overview
A responsive college website interface for displaying departments, courses, faculty, students, campus events, admissions and general college information.

## Features
- Responsive navigation with mobile menu
- Hero and college statistics section
- Departments showcase
- Course cards with category filtering
- Faculty directory
- Upcoming events
- Admissions CTA
- Responsive layout for desktop, tablet and mobile
- Interactive JavaScript filtering and event buttons

## Run
Open `index.html` in any modern browser. No build tools or dependencies are required.

## Project Structure
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — interactions and filtering
